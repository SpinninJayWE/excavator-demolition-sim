# 挖掘机拆迁模拟器 · Excavator Demolition Sim

基于 **Vite 7 + React 19 + Tailwind CSS 4 + Three.js + Rapier 物理引擎** 的浏览器 3D 挖掘机拆迁模拟器。开上 20 吨级液压反铲，把仓库、砖楼、塔楼一座座拆平——真实刚性体碎块翻滚堆叠、支撑坍塌链连锁倒塌、合约任务制结算，全部模型、贴图与音效程序化生成，无任何外部素材。

> 说明：项目使用 Vite 7（stable）而非 Vite 8，因为 rolldown 打包器在部分 Windows / 虚拟化环境下存在兼容性 bug（与 tank-battle-3d 同款工程策略）。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 http://localhost:5173）即可游玩。

```bash
npm run build   # 构建生产版本
npm run preview # 预览构建产物
```

## 玩法特性

- **合约任务制**：5 个合约逐步解锁（拆仓库 50% → 推平砖房 80% → 高楼倒塌 70% → 清理废墟 60 块入坑 → 限时拆迁王 ¥30,000），完成结算星级 + 基础奖励 + 时间奖励，金额本地持久化
- **自由拆迁模式**：无时间限制，实时结算拆迁费，想拆哪就拆哪
- **真实破坏物理（Rapier）**：每块砖 / 钢板 / 混凝土板都是独立刚体，铲斗击碎后碎块带真实惯性翻滚、碰撞、堆叠、休眠后自动回收（上限 650 块，保证流畅）
- **支撑坍塌链**：每块建材记录其下方支撑，底部被掏空后上层结构连锁坠落——拆掉墙根，整面墙轰然倒塌
- **铲斗破坏手感**：速度累计伤害 + 高速挥击即时击碎，金属/砖石不同音效与粒子
- **程序化精致建模**：工程黄挖机（履带、回转体、驾驶室、大臂/斗杆/铲斗 + 三组液压缸与连杆实时联动）、红砖房、波纹钢板仓库、混凝土塔楼、车库、砖墙、烟囱等 8 种建筑
- **工地场景**：程序化泥土/围栏纹理、路障锥桶、废弃自卸车、塔吊、废墟堆、回收坑、云层、雾、UnrealBloom 泛光、PCF 软阴影
- **Web Audio 合成音效**：柴油机怠速/负载循环、液压嘶嘶、金属撞击、砖石碎裂、喇叭
- **细节**：连击加成播报、履带扬尘、铲击粉尘与火花粒子、目标建筑脉冲高亮、HUD 玻璃拟态

## 技术栈

- Vite 7（stable，Windows 兼容性最佳）
- React 19 + Tailwind CSS 4（`@tailwindcss/vite` 插件，零配置）
- Three.js 0.185（程序化低多边形建模 + EffectComposer 泛光后处理，ACES 色调映射）
- @dimforge/rapier3d-compat 0.14（刚体物理：碰撞组位掩码、传感器、EventQueue、自动休眠）
- 固定 60Hz 时间步进物理 + 渲染帧插值，动态刚体 <700 时稳定 60fps+

```
    world.js       场景：地面 / 天空 / 光照 / 工地道具 / 回收坑
    mission.js     合约 / 自由模式 / 金钱 / 解锁 / 结算
    camera.js      跟随 / 自由 / 驾驶舱三视角

    constants.js   合约定义 / 键位 / 数值配置

    Hud.jsx        任务面板 / 余额 / 进度 / 视角

    ResultScreen.jsx 结算（星级 / 奖励明细）
    PauseScreen.jsx 暂停
    TouchControls.jsx 触屏虚拟摇杆
```
